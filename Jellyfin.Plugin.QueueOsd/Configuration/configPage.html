Jellyfin Playlist

Bouton file de lecture dans le lecteur vidéo web (icône playlist_play à côté des réglages, ou touche Q) : saison en cours avec navigation entre saisons pour une série, file de lecture sinon. Un clic sur un épisode le lance sans quitter le lecteur.

Play queue button in the web video player: current season with season navigation for a series, play queue otherwise. Click an item to play it in place.

Décocher désactive le bouton sans désinstaller le plugin. Effet au prochain rechargement de la page web (Ctrl+F5), sans redémarrage.

Le script est injecté dans index.html à la volée (aucune écriture sur le disque) et servi par /QueueOsd/jellyfin-queue-osd.js. Si l'icône n'apparaît pas : rechargez la page avec Ctrl+F5, puis vérifiez la console (F12) : [JellyfinPlaylist] v… – playbackManager found.

Source, issues : github.com/k1k4k/jellyfin-playlist
